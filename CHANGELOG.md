# Changelog

All notable changes to this project will be documented in this file.

## [2.0.0] - 2024-11-19

### Added - Priority Queue Implementation
- Priority-based pixel selection algorithm
- Heap data structure (Python heapq)
- Multi-factor priority calculation (complexity, entropy, edge distance)
- O(log n) pixel selection efficiency
- Comprehensive test suite for priority queue
- Detailed documentation (PRIORITY_QUEUE_EXPLANATION.md)

### Changed
- Steganography module renamed to `SteganographyWithPriority`
- Updated README with priority queue information
- Enhanced test coverage

### OS Concepts
- Priority Queue (heapq)
- Scheduling Algorithms (Priority-based)
- Heap Operations
- Resource Allocation

## [1.0.0] - 2024-11-18

### Initial Release
- AES-256 encryption with HMAC
- Self-destruct mechanisms
- Plausible deniability (dual password)
- Basic LSB steganography
- Web interface
- Python CLI application
