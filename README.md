# Secure File Encryption Tool

A file encryption tool with advanced security features including steganography, self-destruct mechanisms, and plausible deniability.

## Features
- 🔐 AES Encryption/Decryption
- 🖼️ Steganography (hide encrypted data in images)
- ⏰ Self-destruct (view limits, expiry dates, failed attempts)
- 🎭 Plausible Deniability (dual-password system)

## OS Concepts Demonstrated
- File I/O operations and system calls
- File metadata management
- Secure file deletion
- System time APIs
- Memory management

## Installation
```bash
git clone https://github.com/Aayu2810/file-encryption-tool.git
cd file-encryption-tool
pip install -r requirements.txt
```

```bash
python src/main.py
```
