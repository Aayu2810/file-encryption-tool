Steganography

Hide encrypted data inside images - invisible to the naked eye

🔍 How LSB Steganography Works:

  • LSB Technique - Modifies least significant bit of each pixel
  • Invisible Changes - Human eye cannot detect the difference
  • Data Capacity - Depends on image size (larger = more data)
  • Format - Best with PNG (lossless), avoid JPEG (lossy)
