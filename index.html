📚 About This Project

This Secure File Encryption Tool is developed as an Operating Systems course project, demonstrating advanced security concepts and encryption techniques.

The project implements multiple layers of security including AES-256 encryption, HMAC authentication, self-destruct mechanisms, plausible deniability, and steganography - all built from scratch.
